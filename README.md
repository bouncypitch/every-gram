# Every Gram

Every gram has to justify itself. An AI mass audit for robots and products: AI proposes, physics decides.

Results are simulations under stated load and material assumptions, not physical tests. Robot data comes from the open-source [Berkeley Humanoid Lite](https://github.com/HybridRobotics/Berkeley-Humanoid-Lite).

- `fe.py`: voxel finite-element solver
- `topo.py`, `patterns.py`, `materials.py`: topology, rib, hollow-core and material strategies
- `product.py`, `server.py`: product link pipeline
- `web/`: site
